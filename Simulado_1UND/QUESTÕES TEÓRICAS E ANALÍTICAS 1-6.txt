Questão 03 Para resolver, precisamos lembrar que em C, quando temos várias atribuições na mesma linha, o programa resolve da direita para a esquerda. Valores iniciais: a=2, b=4, c=5, d=10.

a += b + c;
A expressão avalia primeiro b+c (4+5=9). Em seguida, soma isso ao valor de a: a=2+9=11.
Estado atual: a=11, b=4, c=5, d=10.

b *= c = d - 2;
Resolvemos da direita para a esquerda: primeiro c=10-2=8. Agora c vale 8. Depois, multiplicamos b por esse novo valor de c: b=48=32.
Estado atual: a=11, b=32, c=8, d=10.

d %= a + 3;
Primeiro somamos a+3 (11+3=14). O operador % calcula o resto da divisão. Então $d = 10 \pmod{14}$. Como 10 é menor que 14, o resto é o próprio 10.
Estado atual: a=11, b=32, c=8, d=10.

a += b += c += 5;
Da direita para a esquerda:
c=c+5=8+5=13

b=b+13=32+13=45

a=a+45=11+45=56

Os valores finais são: a = 56, b = 45, c = 13 e d = 10.

a) i < j + 2  2<3+2  2<5. Isso é Verdadeiro. Resultado: 1.

Questão 06

a) O erro de compilação ocorre por causa do escopo da variável. A variável int soma = 0; foi criada dentro das chaves do laço for. Assim que o laço termina, essa variável é destruída da memória. Quando o printf tenta usá-la lá fora, ela não existe mais.

b) O laço for inicia em 1. Ele executa normalmente para i=1,2,3,4. Quando i=5, o comando continue força o laço a pular a parte debaixo (a soma) e ir direto para a próxima rodada. Ele roda para i=6 e 7. Quando i=8, o break encerra o laço imediatamente, interrompendo tudo.

c) Para corrigir, declaramos a soma antes do laço para ela não zerar toda vez e não sumir no final.



C
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0; // Correção: declarada fora do laço para acumular o valor

    for (i = 1; i <= 10; i++) {
        if (i == 5) continue;
        if (i == 8) break;
        soma += i * i; 
    }

    printf("Soma final = %d\n", soma);
    system("PAUSE"); 
    return 0;
}


Valores somados: 12+22+32+42+62+72=1+4+9+16+36+49. Resultado impresso: Soma final = 115.
